## The word

**screaming**

## Why this word

The internet is five billion people in one room, all talking at once,
nobody listening, everyone convinced the room can hear them. Outrage,
hot takes, memes, ads, livestreams, comment sections — every corner of
it is somebody raising their voice to be heard over everybody else
doing exactly the same thing. It is not one app, one site, or one mood:
it is the sound the whole place makes. "Screaming" lands in one beat —
you picture it, you laugh, and then you nod, because it is true.

## Run

```sh
node main.ts
```

This writes the single word to `/output/entry.txt`.
